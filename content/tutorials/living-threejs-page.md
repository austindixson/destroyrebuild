This write-up is the text half of a paired lesson. The video slot above is waiting on `PLACEHOLDER_YOUTUBE_URL` — no invented channel, no fake embed.

## What this lesson covers

1. Vite + TypeScript with a full-viewport WebGL canvas as the primary surface.
2. A custom `ShaderMaterial` on an `InstancedMesh` so the structure is yours, not a stock HDRI skybox.
3. An idle loop with named phases: hold, crack, break, drift, rebuild, weld.
4. Raycast destinations in the same scene so navigation is part of the world.

## Why not a blog theme

A theme solves publishing. It does not solve presence. If the page is dead when you stop scrolling, it is a document. This site is a shop floor: something is always being taken apart and put back.

## Exercise

Carve your own voxel set. Change the explode delay so the core fails first and the scaffold holds. Then invert it. Watch which metaphor feels more honest for the work you are actually doing.
